## Hypothesis and scope

The September 15 real extraction attached unsupported approval/record-keeping
obligations to a substantially faithful core procedure. The existing prompt binds
steps to evidence but does not explicitly distinguish every metadata field from
trusted operator policy. This is a hypothesis, not a deterministic code defect or
proof that a prompt change will work.

Use one independent experimental `source_only` suffix on the unchanged baseline.
Do not inherit r1/r2, unfreeze r3, change schemas, promote a production prompt, or
rewrite old campaign records. Empty source-policy fields do not disable SkillScout
runtime safety; genuine source requirements must remain present and conditional.
