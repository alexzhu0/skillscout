<objective>
Close the 2026-07-19 BLOCKER: a crash-left deterministic temp file permanently blocks later state, manifest, or publication-plan replacement.

Purpose: `AnchoredDirectory._atomic_write_once` uses one deterministic `.<target>.tmp` name and rejects an existing temp before write; a crash (SIGKILL, host or power loss) after O_EXCL creation but before rename leaves a permanent blocker, contradicting the phase recovery criterion (OPS-04). Owner-validated stale-temp recovery under the retained state lock (state, backup, manifest) and under a new publication operation lock restores progress without weakening the fail-closed primitive.
Output: A recovery primitive in localfs, under-lock wiring in state/pipeline, unit coverage for admission/rejection, and a killed-writer subprocess regression proving the pending stage completes without prefix replay.
</objective>
