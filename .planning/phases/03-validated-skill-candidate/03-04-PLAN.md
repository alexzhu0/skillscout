<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local package bytes → validator | Generated/model-influenced files remain untrusted until descriptor and manifest admission. |
| Admitted directory → third-party official validator | A limited external library receives a path only after SkillScout establishes ownership/size/type/mode bounds. |
| Findings → Reviewer gate | Structured report errors determine whether any Reviewer request is allowed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-VAL | Tampering | official/custom validation aggregation | high | mitigate | Fixed family order, official problems/exceptions as errors, independent custom checks, derived counts and error-only pass predicate. |
| T-03-TOCTOU | Tampering / Elevation of Privilege | package filesystem | high | mitigate | Retained lock, no-follow descriptor reads, link/owner/mode/identity checks, exact manifest admission before third-party access. |
| T-03-04-SEC | Information Disclosure | secret/source diagnostics | high | mitigate | Closed pattern IDs and relative paths only; matched bytes, raw exceptions, credentials and absolute paths never enter reports. |
| T-03-04-DOS | Denial of Service | validation input sizes | medium | mitigate | File/package/count/line/token caps and bounded descriptor reads before parsing/scanning. |
</threat_model>
